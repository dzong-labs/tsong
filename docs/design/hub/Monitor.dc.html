glossary

exchange
Trading a caller's token for one Tsong mints for the route's downstream, per RFC 8693.
subject token
The caller's bearer token, from a trusted issuer. Tsong validates it and never forwards it.
audience aud
Who a token is for. Routes allow, require or deny values.
scope scope, scp
What a token lets its holder do. Routes allow, require or deny values.
typ at+jwt
The header that says what kind of token this is, so an ID token can't pass as an access token.
JWKS
A published set of public keys. Tsong fetches issuers' sets and publishes its own.
kid
The key ID in a token's header, naming the key that signed it.
error budget
The failures an objective allows over 30 days before it's missed.
p99
The time within which 99 of every 100 requests finish.
revision 8b0e6d4
One published version of the config file. Each replica serves one.
